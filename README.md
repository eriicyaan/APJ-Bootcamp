# Java Bootcamp

Набор из трёх учебных Java-проектов, выполненных в рамках обучения в Школе 21. Проекты последовательно охватывают базовый Java, ООП, функциональное и многопоточное программирование, а также разработку веб-приложений с использованием Spring.

## Project 01 — Smart Utilities

Набор консольных Java-модулей для решения математических и алгоритмических задач.

**Основные возможности:**

* работа с примитивными и ссылочными типами данных;
* массивы, списки и строки;
* обработка пользовательского ввода и ошибок;
* рекурсивные алгоритмы;
* сортировка массива выбором;
* поиск минимального и максимального значения;
* работа с файлами;
* фильтрация коллекций;
* использование Java Stream API.

**Технологии и инструменты:**

* Java 21 LTS
* Gradle
* IntelliJ IDEA
* Java Collections Framework
* Stream API
* File I/O

## Project 02 — Pet Info

Консольное приложение для работы с моделями питомцев, демонстрирующее основные принципы ООП, функционального и многопоточного программирования.

**Основные возможности:**

* абстрактные классы и наследование;
* интерфейсы и полиморфизм;
* работа с коллекциями;
* функциональный подход и Stream API;
* пользовательский итератор;
* асинхронный запуск задач в отдельных потоках;
* синхронизация завершения параллельных операций;
* обработка некорректных входных данных.

**Технологии и инструменты:**

* Java 21 LTS
* Gradle
* IntelliJ IDEA
* OOP
* Collections Framework
* Stream API
* Multithreading
* `TimeUnit`

## Project 03 — Tic-Tac-Toe Web Application

Веб-приложение «Крестики-нолики», разработанное с использованием Spring. Проект построен на многослойной архитектуре с разделением ответственности между web, domain, datasource и DI-слоями.

**Основные возможности:**

* игровая модель с UUID и игровым полем;
* реализация алгоритма Minimax для хода компьютера;
* валидация состояния игры;
* проверка окончания игры;
* хранение нескольких игр одновременно;
* потокобезопасное хранилище;
* разделение domain, datasource и web моделей;
* преобразование данных с помощью mapper-классов;
* REST endpoint `POST /game/{UUID}`;
* обработка некорректных игровых состояний;
* конфигурация зависимостей через Spring Configuration.

**Архитектура:**

* `web` — контроллеры, модели и mapper'ы;
* `domain` — бизнес-логика, модели и сервисы;
* `datasource` — хранение данных, repository и mapper'ы;
* `di` — конфигурация и Dependency Injection.

**Технологии и инструменты:**

* Java 21 LTS
* Spring
* Spring Web / MVC
* Gradle
* REST API
* Dependency Injection
* IoC
* Multithreading / thread-safe collections
* Minimax algorithm
* IntelliJ IDEA
